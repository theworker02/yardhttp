# yardhttp

Yard URLs and http query parts with stable normalization.

**Site:** https://theworker02.github.io/yardhttp/

## Install / run

```bash
git clone https://github.com/theworker02/yardhttp.git
cd yardhttp
node src/cli.js
node --test
```
